# cover

Попытка решения задачи о покрытии множества с помощью коэффициента Жаккара.

## Определения

### Задача о покрытии множества (Set Cover Problem)

Задано конечное множество $U$ (универсум) и семейство его подмножеств $S = \{S_1, S_2, \dots, S_m\}: \quad \bigcup_{i=1}^{m} S_i = U$. \
Требуется найти подсемейство $C \subseteq S$ такое, что $|C| \to \min - ?: \quad C \subseteq S, \quad \bigcup_{S_i \in C} S_i = U$



### Коэффициент Жаккара

Коэффициент Жаккара — метрика для сравнения похожести двух множеств:

$$
J(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|}
$$

## Алгоритмы решения

### Жадный алгоритм

На каждом шаге выбирается подмножество, которое покрывает больше всего ещё не покрытых элементов. Выбор не пересматривается.

```text
GREEDY-ALGORITHM(U, S):

    uncovered = U #непокрытые \лементы
    cover = ∅ #Покрытия

    while uncovered ≠ ∅:
        S_best = argmax_i |S_i ∩ uncovered| #Выберем подмножество, покрывающее наибольшее количество элементов

        if |S_best ∩ uncovered| = 0:
            return cover, uncovered

        cover += {S_best}
        uncovered = uncovered \ S_best

    return cover
```


Свойства:

- число операций порядка $O(k \cdot m \cdot n)$, где $n = |U|$, $m = |S|$, $k = |\text{cover}|$;
- оптимальность не гарантируется, но

$$
|\text{cover}| \le \left(\ln n + 1\right) \cdot |C^{*}|,
$$

где $C^{*}$ — оптимальное покрытие.

### Почему жадный алгоритм не всегда находит оптимум

Жадный алгоритм невсегда может давать неоптимальное покрытие. Самое большое подмножество может покрыть часть элементов так, что оставшиеся элементы придётся покрывать бОльшим количеством подмножеств.

Приведём пример, когда жадный алгоритм выводит неоптимальный вариант.

- $U = \{1, 2, 3, 4, 5, 6, 7, 8\}$
- $S_1 = \{1, 2, 3, 5, 6\}$, $S_2 = \{1, 2, 3, 4\}$, $S_3 = \{5, 6, 7, 8\}$

Ход жадного алгоритма:

| Шаг $t$ | Выбрано $S_{i_t}$ | Выигрыш $\lvert S_{i_t} \cap R_{t-1} \rvert$ | Осталось $R_t$ |
|---------|-------------------|----------------------------------------------|----------------|
| 1 | $S_1 = \{1, 2, 3, 5, 6\}$ | 5 | $\{4, 7, 8\}$ |
| 2 | $S_3 = \{5, 6, 7, 8\}$ | 2 | $\{4\}$ |
| 3 | $S_2 = \{1, 2, 3, 4\}$ | 1 | $\varnothing$ |

Жадный алгоритм возвращает $C_{\text{greedy}} = \{S_1, S_3, S_2\}$, то есть $|C_{\text{greedy}}| = 3$.

Оптимальное решение:

$$
C^{*} = \{S_2, S_3\}, \qquad S_2 \cup S_3 = \{1, 2, 3, 4\} \cup \{5, 6, 7, 8\} = U, \qquad |C^{*}| = 2
$$

На первом шаге $S_1$ выигрывает у $S_2$ и $S_3$ (5 элементов против 4), но после него оставшиеся $\{4, 7, 8\}$ не покрываются одним подмножеством. К моменту, когда добавлены $S_3$ и $S_2$, подмножество $S_1$ становится лишним: $S_2 \cup S_3 = U$ и без него.

Жадный алгоритм возвращает $C_{\text{greedy}} = \{A, C_5, C_6\}$, то есть $|C_{\text{greedy}}| = 3$.

Оптимальное решение:

$$
C^{*} = \{D_1, D_2\}, \qquad D_1 \cup D_2 = \{1, 2, 5\} \cup \{3, 4, 6\} = U, \qquad |C^{*}| = 2
$$

После выбора $A$ остаётся $R_1 = \{5, 6\}$. На втором шаге любое подмножество даёт выигрыш не больше 1, поэтому при любом выборе среди равных получится не меньше трёх подмножеств. Выбрав $A$ на первом шаге, мы уже не можем получить покрытие из двух подмножеств: ни одно подмножество не содержит одновременно 5 и 6.

### Поуровневый перебор с отсечением (алгоритм проекта)

Точный алгоритм. Комбинации подмножеств перебираются по уровням: на уровне $k$ рассматриваются покрытия, собранные из $k$ подмножеств. Среди них ищется покрытие с максимальным $J(K, U)$.

**Обозначения.** $L_k$ — множество различных покрытий уровня $k$; $\text{Seen}_k = L_1 \cup \dots \cup L_k$ — все покрытия, найденные до уровня $k$ включительно. Для каждого покрытия $K$ хранится кортеж $c(K) = (i_1, \dots, i_k)$ индексов подмножеств, из которых оно собрано.

```text
LEVEL-SEARCH(U, S):

    J(A, B) = |A ∩ B| / |A ∪ B| #коэффициент Жаккара

    combinations = ∅ #покрытие -> кортеж индексов подмножеств
    for i = 1, ..., m: #уровень 1: каждое подмножество - отдельное покрытие
        if S_i ∉ keys(combinations):
            combinations[S_i] = (i)

    seen = keys(combinations) #все покрытия, найденные на любом уровне
    level = 1

    while true:
        best_score = max J(cover, U) for cover ∈ keys(combinations) #лучший коэффициент Жаккара уровня
        best_comb = {cover ∈ keys(combinations) : J(cover, U) = best_score}
        output level, best_score, {combinations[cover] : cover ∈ best_comb}

        if best_score = 1: #минимальное покрытие найдено
            return level, best_comb

        new_combinations = ∅
        for (cover, combination) in combinations:
            for i = 1, ..., m:
                new_cover = cover ∪ S_i

                if new_cover = cover: #подмножество ничего нового не покрыло
                    continue

                if new_cover ∈ seen: #такое покрытие уже получали
                    continue

                seen += {new_cover}
                new_combinations[new_cover] = combination + (i)

        if new_combinations = ∅: #новых покрытий нет, полное покрытие недостижимо
            return level, best_comb

        combinations = new_combinations
        level += 1
```

**Уровень 1.** Каждое подмножество — отдельное покрытие:

$$
L_1 = \{S_1, S_2, \dots, S_m\}, \qquad c(S_i) = (i)
$$

**Переход с уровня $k$ на уровень $k+1$.** К каждому покрытию добавляется каждое подмножество:

$$
L_{k+1} = \left\{ K \cup S_i \;:\; K \in L_k,\ i = 1, \dots, m,\ K \cup S_i \ne K,\ K \cup S_i \notin \text{Seen}_k \right\}
$$

$$
c(K \cup S_i) = c(K) \,\Vert\, (i)
$$

Здесь $\Vert$ — приписывание индекса к кортежу. Условия отсечения:

- $K \cup S_i \ne K$: подмножество должно добавить хотя бы один новый элемент (в частности, повторно взятое подмножество отбрасывается);
- $K \cup S_i \notin \text{Seen}_k$: такое покрытие уже было получено на этом или более раннем уровне. Любое его продолжение достижимо с меньшим числом подмножеств, поэтому повторный разбор не нужен.

**Оценка уровня.**

$$
J_k = \max_{K \in L_k} J(K, U), \qquad B_k = \left\{ K \in L_k \;:\; J(K, U) = J_k \right\}
$$

$B_k$ — лучшие покрытия уровня $k$.

**Остановка.** Перебор заканчивается на первом уровне $k^{*}$, где $J_{k^*} = 1$, или раньше, если $L_{k+1} = \varnothing$:

$$
k^{*} = \min \{\, k \;:\; J_k = 1 \,\}
$$

Так как уровень равен числу подмножеств в комбинации, $k^{*} = |C^{*}|$, а множество $B_{k^*}$ содержит минимальные покрытия.

**Сложность.** Число различных покрытий ограничено величиной

$$
|L_k| \le \min\left( \binom{m}{k},\ 2^{|U|} \right),
$$

поэтому в худшем случае сложность экспоненциальная. Отсечение по $\text{Seen}_k$ уменьшает число рассматриваемых комбинаций.

**Особенность.** Для каждого покрытия $K$ хранится один кортеж $c(K)$. Чтобы получить все минимальные покрытия, нужно хранить для каждого $K$ множество кортежей.

**Результат на примере.** Для контрпримера выше:

- $J_1 = J(A, U) = \dfrac{4}{6} = \dfrac{2}{3}$;
- $J_2 = J(D_1 \cup D_2,\, U) = 1$, поэтому $k^{*} = 2$ и $B_2 = \{D_1 \cup D_2\}$, $c = (4, 5)$ в нумерации $A, C_5, C_6, D_1, D_2$.

Точный алгоритм находит $C^{*} = \{D_1, D_2\}$ там, где жадный алгоритм даёт покрытие из трёх подмножеств.
