# cover

Попытка решения задачи о покрытии множества с помощью коэффициента Жаккара.

## Определения

### Задача о покрытии множества (Set Cover Problem)

Задано конечное множество $U$ (универсум) и семейство его подмножеств $S = \{S_1, S_2, \dots, S_m\}: \quad \bigcup_{i=1}^{m} S_i = U$. \
Требуется найти подсемейство $C \subseteq S$ такое, что $|C| \to \min - ?: \quad C \subseteq S, \quad \bigcup_{S_i \in C} S_i = U$


### Коэффициент Жаккара

Коэффициент Жаккара - метрика для сравнения похожести двух множеств:

$$
J(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|}
$$

## Алгоритмы решения

### Жадный алгоритм

На каждом шаге выбирается подмножество, которое покрывает больше всего непокрытых элементов.

```text
GREEDY-ALGORITHM(U, S):

    uncovered = U #непокрытые \лементы
    cover = ∅ #Покрытия

    while uncovered ≠ ∅:
        S_best = argmax_i |S_i ∩ uncovered| #Выберем подмножество, покрывающее наибольшее количество элементов

        if |S_best ∩ uncovered| = 0:
            return cover, uncovered

        cover += {S_best}
        uncovered = uncovered \ S_best

    return cover
```


### Почему жадный алгоритм не всегда находит оптимум

Жадный алгоритм невсегда может давать неоптимальное покрытие. Самое большое подмножество может покрыть часть элементов так, что оставшиеся элементы придётся покрывать бОльшим количеством подмножеств.

Приведём пример, когда жадный алгоритм выводит неоптимальный вариант.

- $U = \{1, 2, 3, 4, 5, 6, 7, 8\}$
- $S_1 = \{1, 2, 3, 5, 6\}$, $S_2 = \{1, 2, 3, 4\}$, $S_3 = \{5, 6, 7, 8\}$

Ход жадного алгоритма:

| Шаг $t$ | Выбрано $S_{i_t}$ | Выигрыш $\lvert S_{i_t} \cap R_{t-1} \rvert$ | Осталось $R_t$ |
|---------|-------------------|----------------------------------------------|----------------|
| 1 | $S_1 = \lbrace 1, 2, 3, 5, 6 \rbrace$ | 5 | $\lbrace 4, 7, 8 \rbrace$ |
| 2 | $S_3 = \lbrace 5, 6, 7, 8 \rbrace$ | 2 | $\lbrace 4 \rbrace$ |
| 3 | $S_2 = \lbrace 1, 2, 3, 4 \rbrace$ | 1 | $\varnothing$ |

Жадный алгоритм возвращает $C_\{\text{greedy}\} = \lbrace S_1, S_3, S_2 \rbrace$, то есть $|C_\{\text{greedy}\}| = 3$.

Оптимальное решение:

$$
C = \lbrace S_2, S_3 \rbrace, \qquad S_2 \cup S_3 = \lbrace 1, 2, 3, 4 \rbrace \cup \lbrace 5, 6, 7, 8 \rbrace = U, \qquad |C^{\ast}| = 2
$$

На первом шаге $S_1$ выигрывает у $S_2$ и $S_3$ (5 элементов против 4), но после него оставшиеся $\lbrace 4, 7, 8 \rbrace$ не покрываются одним подмножеством. К моменту, когда добавлены $S_3$ и $S_2$, подмножество $S_1$ становится лишним: $S_2 \cup S_3 = U$ и без него.


### Поуровневый перебор с отсечением (алгоритм проекта)

Точный алгоритм: комбинации подмножеств перебираются по уровням, от меньшего числа подмножеств к большему.

На уровне 1 каждое подмножество рассматривается как отдельное покрытие. Затем к каждому покрытию текущего уровня добавляется каждое подмножество, в котором есть хотя бы один ещё не покрытый элемент, и так строится следующий уровень. Если полученное покрытие уже встречалось на этом или более раннем уровне, оно отбрасывается. На каждом уровне определяется максимальный коэффициент Жаккара $J$ с универсумом. Если $J = 1$, универсум покрыт полностью, и перебор останавливается, иначе происходит переход на следующий уровень.

Так как $S_i \subseteq U$, для любого покрытия $K$ верно $J(K, U) = \dfrac{|K|}{|U|}$. Поэтому добавление подмножества с новыми элементами строго увеличивает $J$, а $J(K, U) = 1$ тогда и только тогда, когда $K = U$.

**Обозначения.**

- $L_k$ — множество различных покрытий уровня $k$ (в псевдокоде `combinations`);
- $\text{Seen}_k = L_1 \cup \dots \cup L_k$ — все покрытия, найденные до уровня $k$ включительно (в псевдокоде `seen`);
- $c(K) = (i_1, \dots, i_k)$ — кортеж индексов подмножеств, из которых собрано покрытие $K$;
- $\mu(K)$ — наименьшее число подмножеств из $S$, объединение которых равно $K$.

```text
LEVEL-SEARCH(U, S):

    J(A, B) = |A ∩ B| / |A ∪ B| #коэффициент Жаккара

    combinations = ∅ #покрытие
    for i = 1, ..., m: #уровень 1: каждое подмножество - отдельное покрытие
        if S_i ∉ keys(combinations):
            combinations[S_i] = (i)

    seen = keys(combinations) #все покрытия, найденные на любом уровне
    level = 1

    while true:
        best_score = max J(cover, U) for cover ∈ keys(combinations) #лучший коэффициент Жаккара уровня
        best_comb = {cover ∈ keys(combinations) : J(cover, U) = best_score}
        output level, best_score, {combinations[cover] : cover ∈ best_comb}

        if best_score = 1: #минимальное покрытие найдено
            return level, best_comb

        new_combinations = ∅
        for (cover, combination) in combinations:
            for i = 1, ..., m:
                new_cover = cover ∪ S_i

                if new_cover = cover: #подмножество ничего нового не покрыло
                    continue

                if new_cover ∈ seen: #такое покрытие уже получали
                    continue

                seen += {new_cover}
                new_combinations[new_cover] = combination + (i)

        if new_combinations = ∅: #новых покрытий нет, полное покрытие недостижимо
            return level, best_comb

        combinations = new_combinations
        level += 1
```

**Уровень 1.** Каждое подмножество — отдельное покрытие (если подмножества совпадают, хранится первое):

$$
L_1 = \lbrace S_1, S_2, \dots, S_m \rbrace, \qquad c(S_i) = (i)
$$

**Переход с уровня $k$ на уровень $k+1$.** К каждому покрытию добавляется каждое подмножество:

$$
L_{k+1} = \lbrace K \cup S_i \;:\; K \in L_k,\ i = 1, \dots, m,\ K \cup S_i \ne K,\ K \cup S_i \notin \text{Seen}_k \rbrace
$$

$$
c(K \cup S_i) = c(K) \,\Vert\, (i)
$$
